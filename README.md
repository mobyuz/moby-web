# Moby Web

A static website for the Moby desktop companion robot. This repository contains the Wb0 milestone.

## Getting started on Windows

Use Node.js 24.13.0 and npm 11.6.2. Run these commands in PowerShell.

```powershell
git clone https://github.com/mobyuz/moby-web.git
Set-Location moby-web
npm.cmd ci --ignore-scripts --no-audit --no-fund
npm.cmd run dev
```

Vite prints the local URL in the terminal. The production build goes to `dist/`.

```powershell
npm.cmd run build
npm.cmd run preview
```

## Stack

| Layer | Technology |
| --- | --- |
| UI | React, TypeScript in strict mode, Tailwind CSS |
| Build | Vite, npm lockfile, static HTML, CSS, and JavaScript |
| API contract | Pinned Moby API OpenAPI 3.1 schema and declarations generated by `openapi-typescript` |
| Verification | ESLint, TypeScript, Playwright, GitHub Actions |

The Wb0 landing page runs on its own. `.env.example` shows the local API URL
for a later integration. The browser can read `VITE_` values.
[API contract provenance](contracts/README.md)

## Verification

```powershell
npm.cmd run api:check
npm.cmd run lint
npm.cmd run typecheck
npm.cmd run build
npx.cmd --no-install playwright install chromium
npm.cmd test
```

Playwright checks the production build through Vite Preview. To test using
an existing Chrome installation, set `$env:PLAYWRIGHT_CHANNEL = 'chrome'` in
PowerShell and run `npm.cmd test`.
